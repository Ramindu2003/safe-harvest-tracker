# 🌾 SafeHarvest: Pesticide Safe-Harvest Tracker

### 🚀 Live Demo: [Click here to view the live project](https://incomparable-kulfi-8f8afe.netlify.app/generator.html) 

## 📌 The Problem
In many agricultural sectors, farmers often harvest crops before the pesticide's Pre-Harvest Interval (PHI) is complete. This leads to severe long-term health issues (such as CKDu in Sri Lanka) for consumers due to active chemical residues in everyday vegetables and fruits.

## 💡 The Solution
**SafeHarvest** is a lightweight, web-based traceability platform designed to bridge the trust gap between farmers and consumers. 
* **For Farmers:** A simple dashboard to log the crop name, chemical used, and the safe interval (PHI). It generates a unique QR code to stick on the harvest batch.
* **For Consumers:** Scanning the QR code instantly verifies if the food is safe to consume based on real-time date calculations.

## ✨ Key Features
* 👨🏽‍🌾 **Farmer Dashboard:** Simple, responsive UI to input pesticide spray details.
* 🔗 **Dynamic QR Generation:** Instantly creates a traceable QR code linking to the specific batch data.
* 🛑 **Consumer Verification System:** Color-coded UI (Red for Warning, Green for Safe) based on automated PHI calculation.
* ⚡ **Serverless & Fast:** Fully client-side logic for zero-latency verifications.

## 🛠️ Tech Stack
* **Frontend:** HTML5, Tailwind CSS
* **Logic:** Vanilla JavaScript (ES6)
* **Libraries:** QRious.js (for QR Code generation)
* **Deployment:** Netlify Drop
